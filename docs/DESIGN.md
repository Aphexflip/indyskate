# IndySkate Design System

## Chosen direction
Concept 3: minimal archive.

The interface is intentionally restrained so the media and history carry the visual weight.

## Visual rules
- Off-white or white page background.
- Black primary typography.
- Thin neutral divider rules.
- Large headings with tight tracking.
- Small monospace-style metadata.
- Generous negative space.
- Large real photography and video when available.
- Original media remains in its native color treatment; do not force black-and-white.

## Avoid
- Fake archival imagery.
- Decorative skate clichés.
- Gratuitous animation.
- Excessive rounded cards.
- Gradients/glassmorphism.
- Generic startup/SaaS layout patterns.
- Unverified dates, credits, names, or locations.

## Interaction rules
- Navigation must remain obvious.
- Archive categories use simple expandable sections.
- Media should play in-site when the source/platform supports legal embedding.
- Every content item should clearly expose useful metadata and provenance.
- The site should remain fast and usable on mobile.

## Mental model
The site should feel like a serious independent skate archive that happens to be on the web: direct, legible, durable, and media-first.
